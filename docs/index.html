Contoh pemasangan Asisten Administrasi

Tombol Tanya Asisten di pojok kanan bawah dipasang oleh satu baris script di akhir halaman ini. Halaman ini tidak memuat CSS atau JavaScript chat apa pun, dan tidak memanggil API.

Halaman ini dibuka sebagai berkas (file://). Tombolnya muncul, tetapi peramban menolak menampilkan panelnya karena izin sematan hanya berlaku untuk situs http/https. Sajikan lewat server lokal: cd client/docs && python -m http.server 5500, lalu buka http://localhost:5500/.

embed.js tidak termuat. Pastikan portal (client/) berjalan di http://localhost:3001, lalu muat ulang halaman ini. Langkahnya ada di embed.md.

Pasang di situs Anda

Tempel tepat sebelum </body>, ganti domainnya dengan domain portal:

<script src="https://<domain-portal>/embed.js" async></script>

Bila portal mengisi EMBED_ALLOWED_ORIGINS, domain situs Anda harus terdaftar di sana. Kalau tidak, tombolnya muncul tetapi panelnya ditolak peramban.

Atau cukup tautkan

Halaman /embed juga bisa dibuka langsung sebagai halaman chat penuh:

<a href="https://<domain-portal>/embed">Tanya Asisten Administrasi</a>

Buka halaman penuh (lokal)

Yang bisa dicoba di halaman ini

  1. Tekan Tanya Asisten. Panel terbuka dan kursor langsung di kotak pertanyaan.
  2. Kirim pertanyaan. Jawaban mengalir beserta sumber PDF yang bisa diklik.
  3. Tutup lewat ✕, tombol Tutup, atau Esc, lalu buka lagi. Percakapannya masih ada.
  4. Persempit jendela di bawah 576 px untuk melihat tampilan ponsel.
